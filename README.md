# Concept Diary

A daily log of one machine learning concept at a time, written from memory,
checked against sources, and paired with a small code demo.

**Why this exists:** I'm building toward **Machine Learning for Space Applications**.
Strong fundamentals come first, so I study one concept every day and test whether
it stuck the next morning.

## How each entry works

1. Recall yesterday's concept on a blank page, then mark the result in yesterday's entry.
2. Learn today's concept from my course or one other source.
3. Write the entry closed-book, then correct it.
4. Add a short code demo (about 10 lines) in `code/`.

Every entry follows [`template.md`](template.md): one-sentence definition, the
problem it solves, a tiny worked example, the common mistake, and one question
I can't answer yet.
